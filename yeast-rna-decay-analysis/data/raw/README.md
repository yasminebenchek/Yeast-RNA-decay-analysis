# Raw data

Raw sequencing/count files and lab-generated input files are not included in this repository.

Expected raw inputs, when available locally:

- `exp20_s7_tc1.xlsx`, `exp20_s8_tc1.xlsx`, etc. for DESeq2 comparisons
- `exp20_t0_0.xlsx`, `exp20_t2.5_0.xlsx`, etc. for decay time-course analysis
- FASTA files for codon usage analysis
- BED/gene-list files for MEME motif input preparation
- poly(A) tail reference data, if licensed for reuse

The public GitHub version is designed to show the analysis workflow without redistributing raw academic research data.
