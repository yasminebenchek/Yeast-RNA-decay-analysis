# Project summary

## MSc project

**Topic:** SLAM-seq/RNA decay analysis of yeast transcriptomic adaptation to glucose adaptation.

This project investigated RNA stability and transcriptome regulation in yeast under glucose-related experimental conditions. The analysis used count-based transcriptomic data to estimate RNA decay half-lives, compare conditions, identify differentially expressed transcripts, and investigate possible sequence-level features associated with transcripts of interest.

## Portfolio framing

This repository should be described as a reproducible bioinformatics workflow rather than a raw upload of dissertation scripts.

> Rebuilt MSc dissertation analysis into a reproducible R bioinformatics workflow for yeast RNA decay analysis, including DESeq2 differential expression, transcript half-life modelling, motif preparation, codon usage analysis, and poly(A) tail comparison.
